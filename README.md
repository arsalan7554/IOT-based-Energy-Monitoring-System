# IOT-based-Energy-Monitoring-System
IoT-Based Energy Monitoring System

An Arduino-based energy monitoring project using the ACS712 current sensor, Python serial communication and a web-based dashboard.

The system collects current readings using Arduino, processes and stores the data using Python, and displays the readings through an interactive HTML dashboard with real-time updates and graphical power visualization.

Key Features

- Current monitoring using ACS712.
- Estimated power calculation.
- Arduino-to-Python serial communication.
- Automatic CSV data logging with timestamps.
- Web-based monitoring dashboard.
- Power consumption graph using Chart.js.
- Estimated electricity cost display.
